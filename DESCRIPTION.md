# Podpowiedzi emotek Klubu Smakoszy

Podpowiedzi dla emotek Klubu Smakoszy. Wpisz poczatek komendy i wcisnij
**Tab** - plugin dopelni ja do pelnej emotki.

## Co potrafi

- **Dopelnianie Tabem** - `smo` + Tab daje `smobliz sie`, `smw` + Tab
  przelacza miedzy `smwytrzyj rekawem`, `smwytrzyj dlonia` i `smwspomnij`.
- **Pelne warianty** - emotki ze stalym dopelnieniem podpowiadaja sie w calosci,
  np. `smbeknij ukradkiem`, `smbeknij donosnie`, `smczytaj menu`.

## Instalacja

1. W menedzerze pluginow Arkadia Web Client dodaj plugin **Podpowiedzi emotek Klubu Smakoszy**.
2. Wpisz `sm` i wcisnij Tab, zeby sprawdzic, czy dziala.

## Prywatnosc

Plugin nic nie zapisuje i nie wykonuje zadnych zapytan sieciowych.
